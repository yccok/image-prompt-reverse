# 图片类型识别维度表

用于步骤 2「识别图片类型」。先判定类型，再按该类型的**关注重点**填充 0–6 字段。

## 一、类型判定清单

| 类型 | 典型特征 |
|---|---|
| 人像/写真 | 以人物为画面核心，强调面部/身材/妆造/情绪，常为棚拍或环境人像 |
| 电商产品 | 单一或少量商品，白底/纯色底或场景化陈列，强调材质与卖点 |
| 海报/平面设计 | 有明确版式、标题文字、图形元素，商业宣传属性强 |
| 风景/建筑 | 自然风光、城市景观、室内外空间建筑，强调空间与透视 |
| 插画/动漫 | 手绘/数字绘画/二次元风格，非写实摄影质感 |
| 美食 | 以食物为主体，强调色泽、质感、摆盘与食欲感 |
| UI/界面 | 软件/网页/App 截图、界面设计稿 |
| Logo/图标 | 品牌标识、图形符号、图标 |
| 宠物 | 以动物为画面核心 |
| 其他 | 无法归入以上任一类的图片 |

判定可多标签（如"人像+海报"），主类型用于文件命名。

## 二、统一抽取维度（所有类型都过一遍）

主体 · 场景/背景 · 构图与镜头 · 光线 · 色调 · 风格与媒介 · 质感细节 · 情绪氛围 · 文字/元素

## 三、各类型关注重点（填充时的侧重点）

- **人像/写真**：皮肤与毛发细致刻画、五官与妆造、身材与姿态、眼神与情绪、服饰材质、布光（轮廓光/补光）、背景干净度。
- **电商产品**：产品外形与材质（金属/玻璃/布料/塑料）、光泽与反射、logo 与文字、背景纯净度、阴影与地面接触感、拍摄角度（正面/45°/俯视）。
- **海报/平面设计**：版式结构、主标题与副标题文字内容与字体、图形与装饰元素、色彩体系、留白与视觉动线、整体调性。
- **风景/建筑**：地形与层次、天际线、透视与消失点、气候与时间、天空与云、空间纵深、前中后景关系。
- **插画/动漫**：画风（日系/欧美/厚涂/线稿）、笔触与线条、配色、角色设定、透视与场景风格化程度。
- **美食**：食物色泽与质感（油光/水汽/焦脆）、摆盘与餐具、蒸汽/酱汁细节、桌面环境、食欲感光线。
- **UI/界面**：布局栅格、组件与配色、字体层级、留白、图标风格、整体产品调性。
- **Logo/图标**：造型与几何结构、对称性、配色、正负形、应用场景、简洁度。
- **宠物**：品种与毛色、毛发质感、表情与动作、眼神、环境与背景。

## 四、置信度表达

判定后在回显中给出一句理由，例如："判定为【电商产品·美妆】，理由：单一瓶身居中、纯色背景、强调瓶身反光与材质。"
